# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `xsslab`, please do not open a public issue. Instead, report it privately to:

**security@example.com**

Please include:
- A descriptive summary of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact and affected components.

Security reports receive an initial response within 48 hours. Validated issues will be patched promptly in a minor security release.
